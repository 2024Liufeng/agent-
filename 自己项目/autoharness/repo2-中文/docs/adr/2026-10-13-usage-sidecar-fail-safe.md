# 在使用观察期间保留不可用的 skill sidecar

## 背景

Skill 和 Read Hook 承诺只做观察、以 fail-safe 方式计数，并且不干扰宿主 skill。损坏的 JSON sidecar、非对象 JSON 或格式错误的计数器目前会以异常形式逃出 Hook。这些属于由本项目管理的元数据故障，不能证明宿主工具本身失败。

## 决策

当 sidecar 所有权查询或计数增加遇到文件系统、解码或结构/类型转换错误时，返回 `counted:false` 和 `sidecar_unavailable`。保留严格的 sidecar 读取器和原子写入；绝不能只是为了记录一次使用事件而修复或重置元数据。保留已有的未知/非 agent 结果和健康计数结果。

## 备选方案

用空对象替换损坏的元数据可能破坏所有权信息和计数器。吞掉所有异常会掩盖已知元数据边界之外的编程错误。全局修改 `sidecar.read` 会改变这个观察范围之外的生命周期和 Promoter 决策。

## 后果

不可用的元数据会跳过一次计数，并保持原状供诊断。这明确表示少计一次，而不是声称操作成功；健康符号和后续事件仍可继续计数。不会为不属于本项目的符号创建 sidecar 或 skill。其他元数据消费者保留原有错误行为。

## 验证
