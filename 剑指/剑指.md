- **工具接入与通信协议：** 熟悉自定义工具开发、注册与调用流程，具有基于 FastMCP 构建 MCP 服务及接入外部工具的实践经验，理解 A2A 智能体通信和 ANP 服务发现的基本思想。

- **模型微调与强化学习：** 理解 LoRA 参数高效微调、SFT 监督微调与 GRPO 强化学习的基本原理，熟悉数据准备、训练参数配置、奖励函数设计及模型评估流程，具有配套训练示例的运行经验。

## 项目经验

### 多 Agent 智能购物助手

**技术栈：** Python、HelloAgents、FastAPI、Vue 3、TypeScript、SSE、DrissionPage、Tavily

**项目描述：** 开发支持自然语言商品发现、跨平台比价和预算推荐的购物助手，由主 Agent 根据需求委派专业子 Agent，并在需要登录或补充信息时请求用户参与、续接任务。

- **多 Agent 协作：** 基于 HelloAgents 原生 ReActAgent、TaskTool 和 ToolRegistry，构建主协调 Agent 与商品发现、平台比价、推荐三个子 Agent，实现按需任务委派、工具调用及结果整合。
- **人工介入与任务续接：** 扩展 Agent 执行边界，在提问成功或必需配置缺失时停止本轮后续工具调用；保留原 Agent 历史，结合会话状态与待回答问题，在用户回复后继续处理原任务。
- **浏览器工具与资源管理：** 封装京东、淘宝、拼多多页面读取工具，使用共享 Edge 实例和独立标签页管理搜索；通过同一 Profile 复用登录状态，并以锁和活动标签页计数协调有头登录与无头搜索的资源切换。
- **实时进度与前后端交互：** 使用 FastAPI、asyncio.Queue 和 SSE 推送主 Agent、子 Agent 及工具执行事件，前端以对话区和进度区展示任务状态；支持断线后重新订阅，并避免重连重复启动任务。
- **异常处理与验证：** 区分未登录、登录态无法确认、验证码、空页面和配置缺失等状态，保留逐平台有效结果及错误原因；编写登录检测与配置缺失处理测试，覆盖任务暂停、错误传递等关键边界。

### 自动化深度研究系统｜案例复现与功能扩展

**技术栈：** Python、HelloAgents、FastAPI、Vue 3、TypeScript、SSE、Tavily、Qdrant、Embedding

**项目描述：** 基于 HelloAgents 复现深度研究系统，并扩展 PDF 资料检索能力。系统根据研究主题拆分子任务，结合本地文档和网页资料生成带来源的研究报告，支持研究进度展示与笔记持久化。

- **多智能体研究流程：** 基于原有 TODO 驱动流程，由研究规划、任务总结和报告撰写角色协作，将研究主题拆分为包含目标、检索词和执行状态的子任务；通过多线程并发执行子任务。
- **本地 RAG 接入：** 复用 HelloAgents 文档解析、分块和 Embedding 能力，使用 Qdrant 保存 PDF 片段及向量；根据各子任务的查询词检索相关片段，并通过知识库 ID 限定检索范围。
- **多来源证据整理：** 将文档片段与网页搜索结果统一整理，保留文件名、片段定位信息或网页链接，进行来源去重和上下文长度控制；为总结与报告生成提供可追溯的证据。
- **笔记协作与报告生成：** 沿用 NoteTool 记录任务状态与总结，汇总子任务结果生成 Markdown 报告；对引用编号进行来源校验，并展示文档与网页参考来源。
- **流式交互与异常处理：** 基于 FastAPI、SSE 和 Vue 展示研究进度、检索来源及工具调用；处理单路检索失败、资料不足等情况，并记录关键阶段日志。
