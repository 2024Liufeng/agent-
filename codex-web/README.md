# Codex Mobile

单用户、手机优先的 Codex 聊天工作台。Node.js 22+，无需前端构建。后端运行 Codex app-server，DSH 使用长期 ACP 子进程。默认继承服务器已登录的 Codex 配置和 DSH 模型配置。

首次在此目录执行 `npm ci`，之后执行 `npm start`，打开 `http://127.0.0.1:3088`。默认工作项目为相邻的 `正在写的项目/spider_agent_cg`，可用 `WORKSPACE` 指定绝对路径。默认浅色界面，没有底部导航；左上角查看可折叠历史，右上角是唯一的新建会话入口，运行中可追加指令或停止。[批准的设计图](design/README.md)随源码保存。

## 云服务器配置

安装并登录 Codex CLI，安装并配置 DSH。设置 `WORKBENCH_TOKEN` 为私有随机令牌。用 HTTPS 反向代理连接默认的本地 3088 端口，代理需关闭事件流缓冲。令牌在网页登录框输入。`HOST` 可配置监听地址，非本地地址强制要求访问令牌。

可配置 `PORT`、`WORKSPACE`、`CODEX_BIN` 和 `DSH_BIN`。Linux 通常可直接使用 PATH 中的 `codex` 和 `dsh`。Windows 自动查找 npm 安装的 DSH JS 入口，也可以设置 `DSH_BIN` 为 node.exe 的绝对路径、`DSH_ENTRY` 为 `@deepseek-ai/dsh/lib/bin.js` 的绝对路径。DSH 版本应与实际验证过的部署版本固定。

本机 DSH 已验证版本为 `0.2.1-rc.2`。首次启动会加载大量插件，默认启动等待为 180 秒，可通过 `DSH_STARTUP_TIMEOUT_MS` 调整。默认单轮执行等待 30 分钟，可用 `DSH_TASK_TIMEOUT_MS` 调整，超时会关闭 Worker 并把当前任务记为失败。

DSH 使用独立的 `.data/dsh` 保存配置和会话，可通过 `DSH_WORKER_HOME` 调整。方舟 Coding 路由写在 `acp.patch.yml`，使用模型 ID `deepseek-v4-1-flash-261017`。私有密钥放在忽略的 `.data/provider.env`，内容是 `ARK_API_KEY=你的密钥`，重启服务生效。也可直接通过进程环境传入。使用 `DSH_MODEL` 覆盖具体模型 ID。

当前执行 Worker 默认关闭推理，由 Codex 提供方案并审查；模型输出容量设为 32,768，防止常规编码时推理耗尽输出预算。已实际验证方舟接口接受该上限与 `thinking: disabled`。复杂任务由 Codex 接手；DSH 的输出上限停止会明确显示，并可继续同一 ACP 会话。

## DSH 调度

仓库 `.agents/skills/dsh-delegation/SKILL.md` 由新 Codex 会话读取。服务提供新建、恢复、发送、查询任务、取消的 Worker API，`worker-client.mjs` 供 Codex 从命令行调用。新建得到 sessionId，发送得到 job id，查询任务可读取 ACP 更新与 stopReason，后续指令复用同一个 sessionId。

默认 YOLO 使用完整访问。关闭 YOLO 后 Codex 和 DSH 都改用工作区写入模式，审批策略拒绝自动提权。切换权限后需新建 DSH 会话，避免恢复旧会话的权限。操作系统权限以服务运行账号为边界。

输入框左下角模型按钮打开模型设置，支持服务端模型目录、思考强度和 Fast；高级运行设置提供 DSH 自动协作、YOLO、上下文限制及自动压缩阈值。运行中的任务结束后才能修改。选择值从下一轮提交，运行时确认值和用量在设置中展示。Fast 描述来自模型目录，不固定消耗倍数。上下文目录上限与运行时有效窗口分别展示。

上下文留空时采用服务端配置；服务端未配置时使用模型目录容量，并按 80% 设置自动压缩阈值。恢复自动也会覆盖会话上一轮的自定义限制。思考强度留空时采用所选模型的默认强度。

顶部工作区名称打开最近工作区，选择“打开文件夹”浏览服务器已有目录，支持磁盘/目录快捷入口、面包屑和上一级；确认当前目录后才添加工作区。历史按工作区筛选，新会话绑定当前工作区，共享其文件，聊天上下文独立。项目偏好保存在忽略的 `.data/workspaces.json`，每轮绑定 Codex 会话并委托 DSH 时带入。默认 SpiderAgent 偏好优先试采、不默认运行单元测试。

`GET /api/directories?path=绝对路径` 返回当前目录、上一级、子文件夹、快捷目录与面包屑，复用网页登录令牌，仅返回目录。省略 path 时从默认项目的父目录开始。可用 `WORKBENCH_DATA_DIR` 指定独立会话存储目录，供隔离的运行验收使用；它不改变模型凭据来源。

DSH `status` 默认回传精简摘要、操作步骤与结果，需要诊断时再用 `details JOB_ID`。活动卡片包含文件或命令、执行状态和耗时，历史工具记录继续兼容。历史未记录的耗时不会补造。

## 当前实现与验证范围

会话和网页消息保存在忽略的 `.data/`，服务重启后通过 thread/resume 恢复 Codex 上下文。网页断开期间任务继续运行，重新打开页面读取服务端记录。服务器进程退出时未完成的轮次显示中断提示。

本机已验证 Codex 的真实对话，以及 DSH ACP 创建会话、使用方舟 DeepSeek 1017 连续两轮修改临时文件。当前不包含服务器部署、语音和附件输入。目标服务器仍需验证登录、进程依赖和部署网络。服务仅供一个可信用户使用。
